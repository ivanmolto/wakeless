WAKELESS — PRODUCTION MARK PACKAGE

PALETTE (exactly two colours)
Near-black: #171819
Off-white: #F6F5F1
No gradients, extra colours, blur, glows, or raster effects.
Route opacity: 25% (the same near-black/off-white ink as the wave).

TYPEFACE
Inter Display Medium (500), converted to vector glyph outlines.
The earlier AI-rendered visual mockup did not disclose an actual font file;
this is a close production reconstruction, not a claim of identical hidden font metadata.
Tracking adjusted by -2.2 viewBox units at the outlined wordmark scale.
No font installation required; no font files included.

COMMON GEOMETRY
All marks use the same immutable cubic Bezier wave curve (512-unit source).
App icon: stroke 34/512. Favicon: stroke 58/512 for 16 px legibility.
This changes thickness, not the underlying path or shape.
Paths use four irregular cubic routes, with crossings and a shorter ending path.
Route segments remain editable Bézier paths (dashed strokes), not bitmaps.
512-tile corner radius: 112/512 ≈ 21.9%.

FAVICON / favicon
favicon.svg — scalable CSS colour-scheme switching: dark tile by default,
               light tile under prefers-color-scheme: dark (per specification)

favicon-[16|32|48|64]-[dark|light].svg — source for each tile
favicon-[16|32|48|64]-[dark|light]@1x.png — true pixel size
favicon-[16|32|48|64]-[dark|light]@2x.png — 2x pixel size
No dotted routes in favicons.

FLAT MARK / flat-mark
wave-dark.svg, wave-light.svg — bare wave, transparent background
wave-paths-dark.svg, wave-paths-light.svg — wave + routes, transparent
The *-dark variants use off-white ink for dark backgrounds;
the *-light variants use near-black ink for light backgrounds.
Each has @1x.png (512 square) and @2x.png (1024 square).

WORDMARK / wordmark
wordmark-dark.svg, wordmark-light.svg — outlined text and identical bare wave
wordmark-dark.png, wordmark-light.png — transparent, nominal size
wordmark-[dark|light]@1x.png and @2x.png — transparent
No rounded pill or background.

PRODUCTION NOTE
Geometry was reconstructed as editable SVG from the approved visual
references, not auto-traced from a hidden original design/Figma document.
It is a faithful vector interpretation, but cannot be guaranteed pixel-identical
to the earlier AI-generated concept renders. The two-colour production palette
is defined here; earlier mockups did not carry authoritative hexadecimal values.
